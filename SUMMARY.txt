PROJECT OVERVIEW
----------------
LiteLLM is a unified Python library and proxy server that provides a standardized 
interface for calling multiple Large Language Model (LLM) API providers using the 
OpenAI format. It acts as an LLM Gateway, translating requests to various providers 
(Bedrock, Huggingface, VertexAI, TogetherAI, Azure, OpenAI, Groq, Anthropic, etc.) 
and returning consistent OpenAI-formatted responses.

KEY FEATURES
------------
1. Unified API Interface
   - Translate inputs to provider-specific completion, embedding, and image 
     generation endpoints
   - Consistent OpenAI-format output across all providers
   - Support for 100+ LLM providers

2. LiteLLM Proxy Server (LLM Gateway)
   - Track spending and usage across multiple projects
   - Load balancing across multiple deployments
   - Virtual key management with budgets and rate limits
   - Authentication hooks and custom logging
   - Cost tracking and rate limiting per project/API key/model
   - Web UI for management (available at /ui)

3. Reliability Features
   - Retry/fallback logic across multiple deployments
   - Router for intelligent request distribution
   - Async support for high-performance applications
   - Streaming support for all models

4. Observability & Logging
   - Pre-defined callbacks for logging tools (Lunary, MLflow, Langfuse, 
     DynamoDB, S3, Helicone, Promptlayer, Traceloop, Athina, Slack)
   - OpenTelemetry integration
   - Prometheus metrics support

Quick Start:
1. Clone repository
2. Install dependencies: make install-dev
3. Run tests: make test-unit
4. Format code: make format
5. Run linting: make lint

Proxy Server Development:
1. Install proxy deps: make install-proxy-dev
2. Set environment variables (LITELLM_MASTER_KEY, LITELLM_SALT_KEY)
3. Start services: docker compose up db prometheus
4. Run proxy: python litellm/proxy_cli.py
5. Access UI: http://localhost:4000/ui

USAGE EXAMPLES
--------------
Basic Usage:
```python
from litellm import completion
response = completion(
    model="openai/gpt-4o",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

Async Usage:
```python
from litellm import acompletion
response = await acompletion(
    model="anthropic/claude-sonnet-4-20250514",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

Streaming:
```python
response = completion(model="openai/gpt-4o", messages=messages, stream=True)
for chunk in response:
    print(chunk.choices[0].delta.content or "")
```

Proxy Server:
```bash
litellm --model huggingface/bigcode/starcoder
# Server runs on http://0.0.0.0:4000
```
